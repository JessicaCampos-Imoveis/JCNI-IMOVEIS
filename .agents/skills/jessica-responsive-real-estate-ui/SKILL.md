# Jessica Responsive Real Estate UI

1. Treat the PRD and screenshots/Figma exports as the visual source of truth.
2. Match structure, hierarchy, spacing rhythm, cards, search, CTAs, and responsive behavior.
3. Do not copy third-party logos, protected photos, text, menu names, or brand identity.
4. Never add blobs, orbs, bokeh, random gradients, generic hero sections, fake content, or decorative 3D illustrations.
5. Prefer real Jessica/property imagery, clean header, strong search block, dense cards, dark footer, and controlled theme tokens.
6. Admin must be operational: tables become cards, long forms use tabs/steps, critical actions need confirmation.
7. Validate 390px, 768px, 1366px, 1440px, and 1920px with browser screenshots when possible.
